# Repositorio Maestro de Guías de Excelencia Operacional Microsoft (M365 E5 + Complementos y Agentes IA)

**Fecha de validación técnica:** `2026-11-11`  
**Alcance:** 23 módulos tecnológicos (`00` a `22`) alineados a **NIST Cybersecurity Framework (CSF) 2.0 (CSWP 29)**, **Microsoft Zero Trust Architecture** y **MITRE ATT&CK**.

## Arquitectura de Entregables por Módulo

Cada carpeta numerada contiene exactamente cuatro artefactos sincronizados bajo el esquema canónico `v2.0`:
1. **Guía Maestra en Markdown (`.md`)**: 15 secciones ejecutivas y operativas, diferenciando explícitamente hechos documentados `` `[Verificado MS Learn]` `` de criterios consultivos `` `[Decisión / Propuesta Editorial]` ``.
2. **Contrato Estructurado de Datos (`.json`)**: Fuente única de verdad validada en UTF-8.
3. **Libro Operativo y de Auditoría (`.xlsx`)**: 9 hojas con tablero de fórmulas dinámicas, checklists por cadencia con listas desplegables, RBAC/PIM, consultas KQL/Graph, KPIs y mapeo NIST CSF 2.0.
4. **Aplicación Interactiva Autocontenida (`.html`)**: Dashboard dinámico con filtros multi-criterio, seguimiento de progreso, buscador KQL con copiado en 1 clic, modo claro/oscuro y cero dependencias externas.

## Publicación Directa en GitHub Pages

La carpeta `GitHub_Pages/` (o la raíz misma del repositorio) es **100 % estática, autocontenida y libre de errores CORS** (`file://` y `https://`):
1. Subir el contenido de `GitHub_Pages/` a la rama `main` de un repositorio GitHub.
2. Confirmar la presencia del archivo `.nojekyll` en la raíz publicada.
3. En `Settings > Pages`, seleccionar `Deploy from a branch > main / (root)`.
