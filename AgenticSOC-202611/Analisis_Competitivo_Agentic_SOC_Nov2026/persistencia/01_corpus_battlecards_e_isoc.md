On either path, deterministic workflows or autonomous agent teams, customers must trust agents enough to turn them on. Use th ese to steer 
the conversation from features to trust, where Perception leads.
OBJECTION HANDLING: ACKNOWLEDGE, THEN REPOSITION
WE HEAR
“We’re not ready to let AI act on its own.”
REPOSITION
Agree, and you don’t have to. Start with governed workflows and human-
in-the-loop gates per agent class; autonomy expands only as you’re ready.
WE HEAR
“How would we know what an agent did, 
and why?”
REPOSITION
Every action is auditable: one control plane across every agent, with a 
reasoning trail that shows what happened and why.
WE HEAR
“Google’s agents are GA and Perception 
isn’t.”
REPOSITION
Compare scope, not timing. Google’s agents are cloud/code-scoped; 
Perception spans the full SOC estate on one graph, included in E5 at GA.
WE HEAR
“CrowdStrike’s SafeMind benchmarks look 
stronger.”
REPOSITION
Benchmarks aren’t outcomes. Ask for verified closure and safe recovery 
across the whole estate, not just one vendor’s telemetry.

03
“Can you audit what every agent did, and why, across all 
your vendors?”
Opens governance and one control plane.
04
“If an agent took the wrong action, how would you roll it 
back?”
Leads to human control and safe recovery.

Project Perception — objections and how to respond
“We can’t let agents act autonomously in our environment.”
Agents ask for user approval on critical actions. Each runs under a dedicated Entra Agent ID

“Isn’t this included in our E5 Security Copilot benefit?”
No — Project Perception is not part of the M365 E5/E7 Security Copilot benefit. It is charged 
as consumption; SCUs are used for the preview. Be direct on this early so commercial 
expectations are set correctly.
“It only works on Microsoft data.”
At launch and in preview Perception runs inside Defender on Defender XDR data. It will 
extend to Microsoft Sentinel data, reaching 450+ enterprise connectors including third-party 
security tools.
“Isn’t this just Security Copilot rebranded?”
They are distinct. Security Copilot assists an analyst with a task. Project Perception is a 
coordinated multi-agent system that takes an objective and runs red, blue and green agents 
end to end — task assistance versus an operating system for defense.
“Google and CrowdStrike already auto-remediate today.”
Auto-patching code is one slice of risk, and CrowdStrike's SafeMind loop is unproven in 
production. Perception runs the operation — detect, investigate, contain and harden across 
the estate. Ask: when an identity is compromised at 2am, which of their agents contains it?
“Will our data be used to train your models?”
No. Project Perception does not use customer data to train models. Data from your 
environment may be used only to tune agents within your own tenant, under Microsoft’s 
existing privacy and compliance commitments.
