## Política de referencia

- Registrar edición, fecha de publicación, URL y fecha de consulta.
- No citar números de técnicas ni conteos sin versión/extracción.
- No atribuir obligatoriedad a guías, comunidades o bases de conocimiento.
- ISO es contenido con licencia; enlazar y registrar metadatos, no copiar extensamente.
- Verificar requisitos legales con Legal/DPO y jurisdicción concreta.
- Mantener equivalencias como mapeos bidireccionales, no como sinónimos.

## Organizaciones y división de funciones

| Organización | Rol típico |
|---|---|
| ISO / IEC | estándares y guía internacional mediante consenso |
| NIST | publicaciones, marcos y taxonomía de riesgo/privacidad/IA |
| ENISA | inteligencia y recomendaciones de ciberseguridad de la UE |
| MITRE | bases de conocimiento de comportamiento y defensa |
| OWASP | recursos abiertos de seguridad software y aplicaciones |
| FIRST | CVSS, EPSS y coordinación/estándares de comunidad |
| The Open Group | publicación y estándares FAIR/Open FAIR |
| Cloud Security Alliance | guía y comunidad cloud/IA, incluido MAESTRO |
| CIS | controles de ciberseguridad priorizados |
| Comunidad LINDDUN / KU Leuven | método y árboles de privacidad |
