# Memoria de trabajo

## Definición y alcance

Sistema de capacidad limitada que mantiene y manipula temporalmente información relevante para razonar y actuar.

**Límites:** No es memoria de largo plazo y se degrada cuando se sostienen demasiados elementos o modelos simultáneos.
