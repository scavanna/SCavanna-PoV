# Inversión

**ID:** `MM-0061` · **Categoría:** Modelos mentales · **Prioridad editorial:** 5 · **Base de definición:** Apoyada por fuentes del catálogo

## Definición y alcance

La inversión como modelo de pensamiento parte del resultado que se quiere evitar y razona hacia atrás para identificar causas, barreras y acciones preventivas.

**Límites:** No sustituye el análisis prospectivo positivo y puede omitir oportunidades si solo se enfoca en evitar fallos.

## Relevancia para el CISO

**Por qué:** Invierte la pregunta para identificar cómo fracasaría una decisión que parece prometedora.

**Caso específico:** Imagina que el SOC agéntico produce un incidente grave; reconstruye acciones y permisos que lo permitieron.

**Pregunta guía:** ¿Cómo haríamos inevitable este fallo y qué barrera interrumpe esa ruta?

**Dominios:** SOC agéntico, Crisis

**Casos CISO adicionales:**

- Aplicar el modelo para identificar cómo podría fracasar una estrategia antes de ejecutarla.
- Incluir una comprobación de resultado indeseado, precursores, barreras y cobertura en decisiones de riesgo, estrategia o incidentes.

## Aplicación para arquitectura, SOC agéntico y Trust Framework

**Arquitectura:**

- Usar el modelo para derivar controles desde rutas de fallo y estados inseguros.

**SOC agéntico — Alta:** Puede incorporarse como regla o bucle observable para identificar cómo podría fracasar una estrategia antes de ejecutarla.

**Trust Framework — Alta:** Aporta directamente a trazabilidad, control o rendición de cuentas al usarlo para derivar controles desde rutas de fallo y estados inseguros.

## Práctica y evaluación

**Ejercicios:**

- Resolver un caso breve aplicando el modelo para identificar cómo podría fracasar una estrategia antes de ejecutarla y explicitar los supuestos.
- Reanalizar una decisión pasada, identificar resultado indeseado, precursores, barreras y cobertura y describir qué habría cambiado.

**Métodos de evaluación:**

- Auditar 10 decisiones y registrar si quedó documentado lo siguiente: resultado indeseado, precursores, barreras y cobertura.
- Comparar dos casos similares, con y sin aplicación explícita del modelo, mediante una métrica de resultado acordada.

**Controles o compensaciones:**

- Usar el modelo como lente, no como regla; contrastarlo con datos y con un modelo alternativo.
- Documentar las condiciones donde no aplica y someter la conclusión a revisión independiente.
