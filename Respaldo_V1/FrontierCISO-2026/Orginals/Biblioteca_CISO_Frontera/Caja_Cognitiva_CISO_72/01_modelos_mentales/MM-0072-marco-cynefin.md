# Marco Cynefin

**ID:** `MM-0072` · **Categoría:** Modelos mentales · **Prioridad editorial:** 9 · **Base de definición:** Apoyada por fuentes del catálogo

## Definición y alcance

Cynefin clasifica contextos como claros, complicados, complejos o caóticos para adaptar el modo de diagnóstico y decisión.

**Límites:** Es un marco de orientación, no una clasificación objetiva permanente; un contexto puede cambiar o contener varios dominios.

## Alias

- cynefin
- cynefin framework

## Relevancia para el CISO

**Por qué:** Adapta el modo de decidir a situaciones claras, complicadas, complejas o caóticas.

**Caso específico:** Durante ransomware se necesita contener ahora; el rediseño de cultura exige experimentos y aprendizaje.

**Pregunta guía:** ¿En qué dominio estamos y qué respuesta sería apropiada allí?

**Dominios:** Crisis, Gobierno

**Casos CISO adicionales:**

- Aplicar el modelo para elegir entre buenas prácticas, análisis experto, experimentación o estabilización.
- Incluir una comprobación de dominio asignado, evidencia de clasificación y enfoque aplicado en decisiones de riesgo, estrategia o incidentes.

## Aplicación para arquitectura, SOC agéntico y Trust Framework

**Arquitectura:**

- Usar el modelo para ajustar patrones de control y respuesta a la naturaleza del contexto.

**SOC agéntico — Alta:** Puede incorporarse como regla o bucle observable para elegir entre buenas prácticas, análisis experto, experimentación o estabilización.

**Trust Framework — Alta:** Aporta directamente a trazabilidad, control o rendición de cuentas al usarlo para ajustar patrones de control y respuesta a la naturaleza del contexto.

## Práctica y evaluación

**Ejercicios:**

- Resolver un caso breve aplicando el modelo para elegir entre buenas prácticas, análisis experto, experimentación o estabilización y explicitar los supuestos.
- Reanalizar una decisión pasada, identificar dominio asignado, evidencia de clasificación y enfoque aplicado y describir qué habría cambiado.

**Métodos de evaluación:**

- Auditar 10 decisiones y registrar si quedó documentado lo siguiente: dominio asignado, evidencia de clasificación y enfoque aplicado.
- Comparar dos casos similares, con y sin aplicación explícita del modelo, mediante una métrica de resultado acordada.

**Controles o compensaciones:**

- Usar el modelo como lente, no como regla; contrastarlo con datos y con un modelo alternativo.
- Documentar las condiciones donde no aplica y someter la conclusión a revisión independiente.
