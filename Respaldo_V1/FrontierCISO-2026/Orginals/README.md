## Cómo utilizarlos

- Para orientarse, comenzar por [los dossiers de la colección](../README.md), que explican alcance, edición y límites.
- Estos paquetes incluyen copias de archivos presentes en las secciones de consulta. Se conservan por trazabilidad; una copia idéntica no constituye otra fuente ni una versión más reciente.
- Los scripts y manifiestos pertenecen al contexto de cada paquete. Algunas rutas de origen apuntan fuera de esta colección; no se presume que sus dependencias estén disponibles.
- Los ZIP y las bases SQLite se mantienen cuando forman parte del entregable. Las cachés de ejecución de Python no son fuentes y se excluyen.
