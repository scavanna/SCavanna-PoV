# 11 — Glosario

- **Atlas:** sistema de perspectivas para explorar conocimiento de ciberseguridad.
- **Taxonomía:** categorías para ubicar contenido.
- **Ontología:** significado, tipos y relaciones válidas.
- **Metamodelo:** tipos de elementos que pueden existir.
- **Grafo:** instancias concretas y relaciones.
- **Corpus:** ensayos, fuentes, claims y evidencia.
- **Sidecar:** artefacto asociado a un ensayo con clasificación y análisis.
- **ChangeSet:** propuesta versionada de cambios; no equivale a aprobación.
- **Evidence:** información que respalda o cuestiona una afirmación.
- **ContextProfile:** condiciones organizacionales que afectan interpretación.
- **Horizonte H:** estado conceptual de evolución, no nivel de madurez.
- **Mecanismo homeostático:** control que preserva variables aceptables durante el cambio.
- **Competency question:** pregunta que prueba si la ontología sirve para recuperar conocimiento útil.
