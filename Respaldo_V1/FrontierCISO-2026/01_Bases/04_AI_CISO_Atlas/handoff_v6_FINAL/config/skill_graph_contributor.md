# Skill — Graph Contributor

## Entrada
Ensayo con ID, clasificación estructural, análisis evolutivo y mapeo curricular.

## Proceso
Identificar entidades → asignar tipos → proponer relaciones → comprobar dominio/rango/dirección → comprobar propiedades/evidencia/contexto → detectar duplicados → generar sidecars → generar ChangeSet `proposed` → registrar validación pendiente.

## Salida
Sidecar JSON/Markdown + ChangeSet JSON. Declarar versiones 5.3/1.0.0. Separar hecho, inferencia, hipótesis y extensión. Nunca afirmar que la ejecución generativa equivale a validación determinista. Nunca aprobar/aplicar.
