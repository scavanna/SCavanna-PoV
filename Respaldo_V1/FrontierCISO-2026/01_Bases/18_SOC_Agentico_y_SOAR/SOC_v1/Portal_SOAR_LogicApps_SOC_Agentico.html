    Arquitectura de Referencia en 5 Capas: Hub SOAR Central Multi-SIEM

    Diseño desacoplado donde múltiples instancias de Sentinel y Splunk On-Premises alimentan un único plano de Case Management, Azure Logic Apps Standard y Microsoft Security Copilot sin duplicar almacenamiento crudo.

    Capa 5 — Cognitiva y SOC Agéntico (Microsoft Security Copilot)
    Security Copilot en M365 E5400 SCUs/mes cada 1.000 usuarios E5 + capacidad elástica para operación 24x7.
    Agentes Nativos e IntegradosPhishing Triage, Alert Triage, Conditional Access y sesiones agénticas en Incident Cases.
    Splunk Plugin + Sentinel MCPConsultas SPL en lenguaje natural y correlación en grafo multi-dominio.
    Logic Apps Skills YAML / MCP ServerEjecución gobernada de enriquecimiento y contención invocada por agentes.
    ▲ Sesiones Agénticas / Skills MCP ▼ Contexto Enriquecido
    Capa 4 — Consola Única y Case Management Centralizado (security.microsoft.com)
    Cola Unificada de IncidentesCorrelación automática de alertas XDR, Sentinel (#1..#N) y Notable Events de Splunk.
    Incident Cases & Generic CasesPlantillas de casos, tareas, SLAs, evidencias adjuntas y RBAC Unificado.
    Tabla SecurityCaseEventAuditoría inmutable de decisiones, SLAs y KPIs operativos MTTA / MTTR.
    ▲ Creación/Actualización de Incidentes y Evidencia ▼ Automation Rules (Created / Updated)
    Capa 3 — Bus SOAR Central Agnóstico al SIEM (Azure Logic Apps Standard)
    PB-01 Inbound NormalizerTraduce JSON de Splunk/terceros a entidades fuertes (UPN, Host, IP, Hash) + idempotencia.
    Orquestador Padre (Router)Desacopla el SIEM de origen de los Child Workflows reutilizables con Try/Catch.
    PB-02/03 Enriquecimiento Zero-CopyEntity 360 (Entra/MDE/MDC P2) + consultas SPL acotadas bajo demanda a Splunk (:8089).
    PB-04/05/06/07 Contención & SyncAislamiento con HITL en Teams (Adaptive Cards) y cierre bidireccional en Splunk ES.
    ▲ Webhook Alertas / Respuestas SPL (:8089 / :8088) ▼ Conectividad Híbrida Zero Trust
    Capa 2 — Conectividad Híbrida y Seguridad (Zero Trust Automation)
    Azure API Management / HTTPSRecepción autenticada OAuth2/mTLS de Notable Events desde Splunk On-Premises.
    VNet Integration + ExpressRoute/VPNAcceso privado saliente desde Logic Apps Standard hacia Splunk API :8089 y FW locales.
    On-Premises Data Gateway / ArcAlternativa sin abrir puertos entrantes + Managed Identities + Azure Key Vault.
    ▲ Solo Alertas Accionables + Extractos Puntuales (Cero Copia Masiva de Logs) ▼
    Capa 1 — Motores de Detección y Almacenamiento en Convivencia Plurianual
    Microsoft Defender XDR (E5)MDE P2, MDO P2, MDI, MDCA, Entra ID P2 y Purview con Custom Detections.
    Defender for Servers Plan 2Servidores híbridos con Azure Arc + AMA (500 MB/srv/día en medidores unificados).
    Sentinel Workspace #1 y #N5 MB/usr/día E5 + fuentes gratuitas + Multi-Workspace / Azure Lighthouse.
    Splunk Enterprise On-PremisesRetiene terabytes de Firewalls, Proxies, OT y Apps legadas sin re-ingesta en Sentinel.
