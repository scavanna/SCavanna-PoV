# Excelencia Operacional Microsoft Security · edición simplificada

Conserva los **23 módulos de la edición 2.0** (11 de noviembre de 2026), con un único índice Markdown. Cada módulo mantiene cuatro herramientas distintas: el procedimiento, el libro editable, el visor y los datos estructurados.

## Uso por control

1. Elegí el módulo y delimitá alcance, dueño, suplente y requisitos de licencia.
2. Usá la **guía** para definir configuración, rutinas por cadencia y respuesta a eventos. Probá los cambios en un piloto autorizado y documentá evidencia y reversión.
3. Trabajá sobre una copia del **Excel** para registrar verificaciones e indicadores. Usá el **visor** para filtrar y seguir las tareas, o el **JSON** para consultar el catálogo estructurado.

El [portal operativo transversal](guias_v2/index.html) busca controles, rutinas y playbooks de los 23 módulos, además de los indicadores y mapeos de referencia. Descargá la carpeta completa para que funcione la navegación. No es un índice de archivos ni ejecuta cambios.
