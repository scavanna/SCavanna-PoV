# Ninja Training de Seguridad Microsoft · edición simplificada

Quince programas de formación en español, con el contenido curricular de la edición 2026. Usá el **mapa del programa** para elegir módulos, **Práctica y referencias** para evaluar y organizar el laboratorio, y el **Excel** para seguir el avance. La [portada interactiva](index.html) conserva la búsqueda en toda la serie, las rutas de aprendizaje y el acceso a cada visor.

**Libros de los programas 01–10:** conservan su protección original; abrilos en Excel con una cuenta autorizada. El curso en Markdown y el visor siguen disponibles si no tenés acceso al libro. Descargá la carpeta completa para la navegación local. Los materiales web externos requieren conexión.

**Fechas de corte:** 6–8 de noviembre de 2026 según el programa. Verificá licencias, disponibilidad y retiros en la documentación oficial antes de aplicar un procedimiento.

## Qué trae cada programa

- **Serie Markdown** (carpeta del programa): `README.md` con el mapa de módulos; `00_Programa.md` con la justificación, el formato Ninja, qué cambió, roles, plan de entrenamiento y tablas de referencia; un archivo por nivel o especialización, más un anexo único de comunidad, evaluaciones, laboratorio y referencias.
- **Guía web interactiva** (`.html`, se abre en cualquier navegador): progreso guardado en tu equipo, búsqueda y filtros, evaluaciones con corrección y certificado al 80 %.
- **Libro de Excel** (uno por programa): plan de estudio con seguimiento y avance, plan semanal, ejercicios, catálogo con enlaces, hoja de respuestas, matriz de laboratorio, tablas de referencia propias del programa, referentes y cambios.

## Rutas sugeridas entre programas

| Ruta | Para quién | Recorrido |
|---|---|---|
| **SOC moderno** | Analistas, respondedores e ingenieros de detección | Sentinel (niveles 1 y 2) → Defender XDR (inicial e intermedio) → Sentinel (nivel 3) → Defender XDR (avanzado y track de excelencia S1–S7) → Security Copilot (intermedio y agentes) |
| **Identidad y preparación para agentes de IA** | Arquitectos y administradores de identidad, dueños de plataformas de IA | Entra (inicial a avanzado) → Defender XDR (módulos de Defender for Identity y Entra ID Protection) → Entra (track de agentes X1–X7) → Security Copilot (agentes) → Purview DSPM y seguridad de datos para IA |
| **Seguridad de los datos** | Equipos de protección de la información y dueños de datos | Purview Information Protection → Purview DLP → Purview DSPM y seguridad de datos para IA → Purview Insider Risk Management |
| **Cumplimiento, registros y legal** | GRC, gestión documental, Legal e investigaciones | Purview Compliance Manager → Purview Ciclo de vida y Registros → Purview eDiscovery y Audit → Purview Communication Compliance e Information Barriers |
| **SOC agéntico (dirección y arquitectura)** | Líderes de SOC, CISO y arquitectos de seguridad | Security Copilot (inicial) → Defender XDR (track de excelencia S1–S7) → Security Copilot (track de agentes X1–X5) → Entra (track de agentes X1–X7) |
| **Seguridad y gobierno de Copilot y agentes** | Administradores de Microsoft 365 y Power Platform, seguridad de datos, SOC, GRC y dueños de la plataforma de IA | Entra (inicial e intermedio) → Purview DSPM y seguridad de datos para IA (inicial e intermedio) → Seguridad de Microsoft 365 Copilot, agentes y Copilot Studio (los cuatro niveles) → Entra (track de agentes X1–X7) → Security Copilot (agentes) |
| **Seguridad en la nube con Defender for Cloud** | Arquitectos de nube, equipos de plataforma, SOC, DevSecOps y FinOps | Defender for Cloud (Base y Avanzado) → Defender XDR (I4 y M6: Defender for Endpoint y vulnerabilidades) → Defender for Cloud (Experto, especialización por workload W1–W7 según los planes activos y track de operación) → Sentinel (nivel 3) → Security Copilot (agentes) |
| **Arquitectura segura para agentes de IA en Azure** | Arquitectos de IA y de nube, ingenieros de plataforma, desarrolladores de agentes, seguridad de datos, SOC y gobierno de la IA | Plan integrado (documento transversal) → Seguridad de agentes de IA en Foundry (nivel 1) → Entra (track de agentes X1–X7) → Defender for Cloud (A1 y A2) → Seguridad de agentes de IA en Foundry (niveles 2 a 4) → Purview DSPM y seguridad de datos para IA → Sentinel y Defender XDR (respuesta) |

El [Anexo de entorno de práctica](Anexo_Entorno_de_practica.md) explica cómo armar un laboratorio funcional con los créditos mensuales de Azure de una suscripción de Visual Studio Enterprise y una prueba de Microsoft 365 E5, qué capacidades no se pueden practicar allí y por qué, y una estrategia para practicar en producción con el riesgo controlado (modos de solo informe, auditoría y simulación, alcance piloto, privilegio justo a tiempo, cambios reversibles y acuerdos con privacidad, Legal y RR. HH.). Cada ejercicio de la serie está etiquetado como **[LAB]**, **[LAB-PARCIAL]** o **[SOLO-PRODUCCION]**.
