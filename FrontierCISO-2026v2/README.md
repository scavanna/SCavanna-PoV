## Un primer recorrido

1. Elegí **un servicio crítico** y acordá con negocio qué pérdida o interrupción no puede tolerar.
2. Registrá **una función, un escenario relevante y su responsable**. No presupongas cobertura por licencia ni por presencia en una matriz.
3. Elegí **un control y una prueba** que cambien una decisión. Definí el alcance, la fuente de evidencia y la fecha de revisión.
4. Medí la línea base antes de pactar la meta. Si falta evidencia, registrá la brecha y pedí una decisión explícita.

## Cómo usar los artefactos

- Abrí el README del recorrido y elegí el archivo de `artefactos/` que corresponda. Para trasladar la biblioteca, conservá juntas las seis carpetas: las guías se referencian entre sí.
- Descargá los libros Excel y trabajá sobre una copia por organización. Las planillas conservan las hojas y fórmulas de su edición de origen; las URLs a documentación pública y a recursos de estudio requieren conexión.
- No se incorporaron borradores, bitácoras, generadores, catálogos candidatos ni visores que duplican las funciones de las guías y libros. Las referencias de otra edición con valor operativo, como el cruce de ransomware con el Plan v1.0, se indican por separado.
