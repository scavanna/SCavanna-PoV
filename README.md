# SCavanna-PoV

Colección de puntos de vista, guías, programas de formación y materiales de trabajo sobre ciberseguridad, gobierno del CISO, Microsoft Security e inteligencia artificial.

La navegación principal es la de **GitHub, mediante archivos README y documentos Markdown**. Los cursos, paneles y visores HTML con funciones propias se conservan como recursos complementarios.

## Cómo consultar los archivos

- **README y Markdown:** leer directamente en GitHub. Cada colección tiene su propio índice; donde existe un catálogo complementario, el README lo enlaza.
- **HTML interactivo:** descargar el archivo o la carpeta correspondiente y abrirlo en un navegador, respetando sus instrucciones y archivos asociados. Se conservan las portadas que forman parte de una aplicación; no se mantienen los índices y exploradores HTML generados que duplicaban los índices Markdown.
- **Excel, Word y PDF:** descargar para su consulta o edición. No son archivos sobrantes por no ser Markdown.
- **CSV, JSON, YAML, SQLite y scripts:** forman parte de las fuentes, catálogos, grafos o herramientas de los paquetes; consultar el README del paquete antes de utilizarlos.

## Fuentes, copias y versiones

La colección integrada y las carpetas temáticas de primer nivel contienen material compartido. Además, [los paquetes de origen](FrontierCISO-2026/Orginals/README.md) preservan antecedentes y generadores. Estas copias no deben interpretarse como nuevas ediciones ni como fuentes independientes.

Se conservan los nombres de las carpetas importadas, incluido `Orginals`, para no introducir más cambios de rutas. La fecha, edición, estado y limitaciones documentadas en cada dossier tienen prioridad sobre nombres como `final`, `validado` o `actualizado`.

Los paquetes de origen pueden contener referencias a rutas locales o entregables que no están incluidos en esta copia. Los índices señalan las ausencias conocidas; la conservación de un documento no implica que todos sus enlaces históricos estén disponibles.

## Criterios de mantenimiento

1. Usar un README como entrada de cada colección y enlaces relativos a archivos presentes.
2. Conservar HTML cuando aporte búsqueda, seguimiento, evaluaciones, paneles u otra interacción propia; evitar generar otra portada HTML para cada directorio.
3. No eliminar fuentes, versiones históricas, archivos de distribución o formatos alternativos solo por compartir nombre o contenido. Antes de deduplicar, revisar procedencia, dependencias y referencias.
4. No incorporar cachés de Python, archivos de bloqueo de Office ni metadatos del sistema operativo. Las exclusiones están en `.gitignore`.
5. Esta organización prioriza GitHub: las URL de los índices HTML retirados no se conservan. Los cambios locales no se publican en GitHub Pages hasta actualizar el repositorio remoto.

Material independiente de estudio y trabajo. Las propuestas y correspondencias documentales no equivalen a controles desplegados, certificaciones oficiales ni asesoramiento legal.
