# Capacidades Microsoft basadas en Microsoft Learn

Fuentes consultadas oficialmente mediante **Microsoft Learn MCP Server** y páginas de Microsoft Learn. Fecha de consulta: 2026-11-18.

## Reglas

- Microsoft Defender XDR correlaciona señales de productos licenciados y aprovisionados.
- La presencia de un servicio no prueba configuración, cobertura, telemetría ni efectividad.
- Licencias, regiones, plataformas y nombres comerciales cambian; validar antes de adquisición o diseño.
- Para OT/IoT, respuesta y aislamiento deben estar autorizados por operación y safety.
- Seguridad Copilot asiste; sus resultados deben ser revisados.
- Azure Backup y Site Recovery requieren RPO/RTO, arquitectura, pruebas y capacidad.
