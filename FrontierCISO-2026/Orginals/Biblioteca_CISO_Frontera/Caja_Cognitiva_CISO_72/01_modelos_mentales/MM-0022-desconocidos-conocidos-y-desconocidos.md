# Desconocidos conocidos y desconocidos

**ID:** `MM-0022` · **Categoría:** Modelos mentales · **Prioridad editorial:** 20 · **Base de definición:** Apoyada por fuentes del catálogo

## Definición y alcance

El modelo distingue lo conocido, lo desconocido reconocido y lo desconocido no reconocido para hacer visibles límites de conocimiento.

**Límites:** No convierte los desconocidos desconocidos en riesgos enumerables; sirve para diseñar exploración y resiliencia.

## Alias

- known unknowns
- rumsfeld matrix
- unknown unknowns

## Relevancia para el CISO

**Por qué:** Separa desconocidos reconocidos de riesgos que aún no tenemos capacidad de observar.

**Caso específico:** Una auditoría de agentes cubre abusos previstos, pero no interacciones nuevas con datos externos.

**Pregunta guía:** ¿Qué sabemos que no sabemos y cómo detectaríamos una sorpresa?

**Dominios:** Gobierno, Trust Framework

**Casos CISO adicionales:**

- Aplicar el modelo para separar incertidumbres identificadas de puntos ciegos potenciales.
- Incluir una comprobación de supuestos, incógnitas conocidas y mecanismos para descubrir sorpresas en decisiones de riesgo, estrategia o incidentes.

## Aplicación para arquitectura, SOC agéntico y Trust Framework

**Arquitectura:**

- Usar el modelo para reservar capacidad de detección, contención y adaptación para amenazas no modeladas.

**SOC agéntico — Media:** Puede orientar agentes y supervisores para separar incertidumbres identificadas de puntos ciegos potenciales, con validación humana.

**Trust Framework — Alta:** Aporta directamente a trazabilidad, control o rendición de cuentas al usarlo para reservar capacidad de detección, contención y adaptación para amenazas no modeladas.

## Práctica y evaluación

**Ejercicios:**

- Resolver un caso breve aplicando el modelo para separar incertidumbres identificadas de puntos ciegos potenciales y explicitar los supuestos.
- Reanalizar una decisión pasada, identificar supuestos, incógnitas conocidas y mecanismos para descubrir sorpresas y describir qué habría cambiado.

**Métodos de evaluación:**

- Auditar 10 decisiones y registrar si quedó documentado lo siguiente: supuestos, incógnitas conocidas y mecanismos para descubrir sorpresas.
- Comparar dos casos similares, con y sin aplicación explícita del modelo, mediante una métrica de resultado acordada.

**Controles o compensaciones:**

- Usar el modelo como lente, no como regla; contrastarlo con datos y con un modelo alternativo.
- Documentar las condiciones donde no aplica y someter la conclusión a revisión independiente.
