# Pensamiento de Sistema 1 y Sistema 2

**ID:** `MM-0109` · **Categoría:** Modelos mentales · **Prioridad editorial:** 23 · **Base de definición:** Apoyada por fuentes del catálogo

## Definición y alcance

El pensamiento de Sistema 1 y Sistema 2 distingue procesos rápidos e intuitivos de procesos lentos y deliberativos que revisan evidencia y reglas.

**Límites:** Es un modelo funcional simplificado; ambos procesos interactúan y no corresponden a módulos anatómicos independientes.

## Alias

- System 1 & System 2 Thinking
- System 1 and System 2 Thinking

## Relevancia para el CISO

**Por qué:** Hace visible la interacción entre intuición rápida y revisión deliberada bajo presión.

**Caso específico:** El analista y el agente coinciden en la primera hipótesis; forzar una segunda pasada con evidencia rival.

**Pregunta guía:** ¿Qué parte de esta conclusión fue automática y cuál fue contrastada?

**Dominios:** SOC agéntico, Trust Framework

**Casos CISO adicionales:**

- Aplicar el modelo para decidir cuándo activar revisión deliberada sobre intuiciones o automatizaciones.
- Incluir una comprobación de respuesta automática, revisión deliberada y cambio producido en decisiones de riesgo, estrategia o incidentes.

## Aplicación para arquitectura, SOC agéntico y Trust Framework

**Arquitectura:**

- Usar el modelo para incorporar escalamiento y fricción cognitiva en decisiones de alto impacto.

**SOC agéntico — Alta:** Puede incorporarse como regla o bucle observable para decidir cuándo activar revisión deliberada sobre intuiciones o automatizaciones.

**Trust Framework — Alta:** Aporta directamente a trazabilidad, control o rendición de cuentas al usarlo para incorporar escalamiento y fricción cognitiva en decisiones de alto impacto.

## Práctica y evaluación

**Ejercicios:**

- Resolver un caso breve aplicando el modelo para decidir cuándo activar revisión deliberada sobre intuiciones o automatizaciones y explicitar los supuestos.
- Reanalizar una decisión pasada, identificar respuesta automática, revisión deliberada y cambio producido y describir qué habría cambiado.

**Métodos de evaluación:**

- Auditar 10 decisiones y registrar si quedó documentado lo siguiente: respuesta automática, revisión deliberada y cambio producido.
- Comparar dos casos similares, con y sin aplicación explícita del modelo, mediante una métrica de resultado acordada.

**Controles o compensaciones:**

- Usar el modelo como lente, no como regla; contrastarlo con datos y con un modelo alternativo.
- Documentar las condiciones donde no aplica y someter la conclusión a revisión independiente.
